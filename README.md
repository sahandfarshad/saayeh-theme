# پوسته‌ی سایه (Saayeh) برای ووکامرس

پوسته‌ی فروشگاهی مینیمال و راست‌چین برای فروشگاه‌های پوشاک، با فونت وزیرمتن، رنگ‌های گرم، تایپوگرافی درشت و تجربه‌ی خرید روان: کشوی سبد خرید، علاقه‌مندی‌ها بدون افزونه، جستجوی زنده، فیلتر سایز/رنگ/قیمت، تسویه‌حساب با نمایش مرحله‌ای، فیلدهای ایرانی و درگاه زرین‌پال داخلی.

- نسخه: 1.0.0
- پیش‌نیازها: وردپرس 6.4 به بالا، PHP 7.4 به بالا، ووکامرس 8 به بالا
- مجوز: GPL-2.0-or-later (فایل `LICENSE`)

## نصب

1. فایل `saayeh.zip` را از پیشخوان وردپرس، بخش **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته** نصب و فعال کنید. پوشه‌ی پوسته باید `saayeh` باشد.
2. افزونه‌ی **ووکامرس** را نصب و فعال کنید.
3. زبان سایت را در **تنظیمات ← عمومی** روی «فارسی» بگذارید تا متن‌های ووکامرس و تاریخ‌ها هم فارسی شوند. (اگر زبان سایت فارسی نباشد، پوسته باز هم راست‌چین است و مهم‌ترین متن‌های فروشگاه را فارسی نشان می‌دهد.)
4. **محتوای نمونه (اختیاری):** افزونه‌ی «درون‌ریز دمو سایه» (`saayeh-demo-importer.zip`) را نصب کنید و از **ابزارها ← درون‌ریزی دمو سایه** دکمه‌ی درون‌ریزی را بزنید. این کار ۶ محصول، ۵ دسته، برگه‌ها، ۳ نوشته‌ی وبلاگ، منوها، کد تخفیف `SAYEH10`، روش‌های ارسال و تنظیمات پوسته را می‌سازد. بسته‌ی دمو در `demo/demo.json` و تصاویرش در `demo/images/` است.
5. بعد از فعال‌سازی، یک بار **تنظیمات ← پیوندهای یکتا** را ذخیره کنید (برای تب «علاقه‌مندی‌ها» در حساب کاربری).

### برگه‌های پیشنهادی

| برگه | محتوا |
|---|---|
| خانه | خالی؛ به‌عنوان برگه‌ی نخست تنظیم شود (پوسته بخش‌ها را خودش می‌سازد) |
| فروشگاه، سبد خرید، تسویه حساب، حساب کاربری | برگه‌های ووکامرس (با کدکوتاه کلاسیک `[woocommerce_cart]`، `[woocommerce_checkout]`، `[woocommerce_my_account]`) |
| علاقه‌مندی‌ها | کدکوتاه `[saayeh_wishlist]` یا قالب برگه‌ی «علاقه‌مندی‌ها» |
| تماس با ما | کدکوتاه `[saayeh_contact]` |

> طراحی تسویه‌حساب و سبد خرید برای حالت **کدکوتاه کلاسیک** ووکامرس ساخته شده است. اگر برگه‌های شما بلوک «سبد خرید/تسویه حساب» دارند، محتوای برگه را با کدکوتاه‌های بالا جایگزین کنید. درگاه زرین‌پال این پوسته هم در تسویه‌حساب کلاسیک کار می‌کند.

## راه‌اندازی درگاه زرین‌پال

درگاه داخل پوسته است (`inc/gateways/class-saayeh-zarinpal.php`) و از API نسخه‌ی ۴ زرین‌پال استفاده می‌کند.

1. به **ووکامرس ← پیکربندی ← پرداخت‌ها** بروید و «زرین‌پال» را باز کنید.
2. تیک **فعال‌سازی** را بزنید.
3. **مرچنت کد** ۳۶ کاراکتری را از پنل زرین‌پال (بخش درگاه‌ها) وارد کنید. هیچ کلید یا کدی داخل فایل‌های پوسته ذخیره نشده است.
4. برای آزمایش، **حالت آزمایشی (سندباکس)** را روشن کنید. در این حالت درخواست‌ها به `sandbox.zarinpal.com` می‌روند و هر شناسه‌ی UUID معتبر به‌عنوان مرچنت پذیرفته می‌شود.
5. واحد پول فروشگاه باید **تومان ایران (IRT)** یا **ریال (IRR)** باشد. مبلغ همیشه به **ریال** برای زرین‌پال ارسال می‌شود (تومان × ۱۰).
6. در صورت نیاز، «گزارش خطا» را روشن کنید تا درخواست‌ها و پاسخ‌ها در **ووکامرس ← وضعیت ← گزارش‌ها** (منبع `saayeh_zarinpal`) ثبت شوند. مرچنت کد در گزارش‌ها پوشانده می‌شود.

**روند پرداخت:** درخواست `payment/request.json` ← انتقال به `StartPay/{authority}` ← بازگشت به `/wc-api/saayeh_zarinpal/` ← تأیید با `payment/verify.json`. کدهای 100 و 101 موفق‌اند؛ کد پیگیری (ref_id) و شماره‌ی کارت ماسک‌شده در یادداشت و متای سفارش (`_saayeh_zarinpal_ref_id`, `_saayeh_zarinpal_card_pan`) ذخیره و به‌عنوان شناسه‌ی تراکنش ثبت می‌شود. اگر مشتری پرداخت را لغو کند (`Status=NOK`)، سفارش در حالت «در انتظار پرداخت» می‌ماند و مشتری به صفحه‌ی پرداخت دوباره برمی‌گردد. خطاها به فارسی نمایش داده می‌شوند.

### افزودن درگاه‌های دیگر

درگاه‌ها از فیلتر `saayeh_payment_gateways` ثبت می‌شوند؛ هر افزونه یا پوسته‌ی فرزند می‌تواند درگاه خودش را اضافه یا درگاه زرین‌پال را حذف کند:

```php
add_filter( 'saayeh_payment_gateways', function ( $gateways ) {
	$gateways['my_gateway'] = array(
		'class' => 'My_Gateway',                  // کلاسی که از WC_Payment_Gateway ارث می‌برد
		'file'  => __DIR__ . '/class-my-gateway.php',
	);
	// unset( $gateways['saayeh_zarinpal'] ); // برای حذف زرین‌پال
	return $gateways;
} );
```

فیلترهای دیگر: `saayeh_zarinpal_request_body`، `saayeh_zarinpal_currency_multipliers`، `saayeh_zarinpal_icon` و اکشن `saayeh_zarinpal_payment_complete`.

## تنظیمات سفارشی‌ساز (نمایش ← سفارشی‌سازی ← تنظیمات پوسته سایه)

| بخش | گزینه‌ها |
|---|---|
| عمومی و رنگ | رنگ تأکیدی (شنی)، شعار کنار لوگو، متن و لینک نوار اعلان، حد ارسال رایگان برای نوار پیشرفت (تومان)، اجبار راست‌چین، اعداد فارسی در قیمت‌ها |
| هیرو صفحه نخست | تصویر، متن کوچک، عنوان، زیرعنوان، متن و لینک دکمه |
| بخش‌های صفحه نخست | نمایش دسته‌بندی‌ها، تعداد محصولات تازه، محصولات ویژه، آخرین نوشته‌ها، عنوان و متن خبرنامه |
| بخش روایت | تصویر، متن کوچک، عنوان، متن، دکمه |
| نوار اعتماد | ۴ مورد (عنوان + توضیح) |
| شبکه‌های اجتماعی | اینستاگرام، تلگرام، واتس‌اپ، ایکس، لینکدین، یوتیوب، آپارات |
| فوتر و نمادها | متن درباره، کد نماد اعتماد (اینماد/ساماندهی؛ فقط تگ‌های `a` و `img`)، کپی‌رایت، ایمیل فرم تماس، تلفن پشتیبانی |

لوگو از **هویت سایت ← لوگو** تنظیم می‌شود. منوها: «منوی اصلی»، «منوی فوتر»، «منوی فوتر (ستون دوم)» و «پیوندهای پایین صفحه». ابزارک‌ها: سه ستون فوتر و وبلاگ.

## امکانات

- **صفحه نخست:** هیرو، کاشی دسته‌بندی‌ها، محصولات تازه، بخش روایت، محصولات منتخب، نوار اعتماد، آخرین نوشته‌ها، خبرنامه (مشترکین در **نمایش ← مشترکین خبرنامه** با خروجی CSV).
- **کارت محصول:** برچسب (متای `_saayeh_badge` یا «تخفیف»/«ناموجود» خودکار)، قلب علاقه‌مندی، افزودن سریع با انتخاب سایز.
- **فروشگاه:** چیپ دسته‌ها، فیلتر سایز/رنگ/قیمت (با پارامترهای استاندارد ووکامرس `filter_size`، `filter_color`، `min_price`، `max_price`) و مرتب‌سازی.
- **صفحه محصول:** دایره‌های رنگ از متای ترم `saayeh_color_hex` (قابل ویرایش در **محصولات ← ویژگی‌ها ← رنگ**)، دکمه‌های سایز با نمایش ناموجودها، شمارنده‌ی تعداد، تب‌های آکاردئونی، «ارسال و مرجوعی»، راهنمای سایز (پنجره‌ی مودال، قابل تغییر با فیلتر `saayeh_size_guide_html`)، محصولات مرتبط.
- **کشوی سبد خرید:** به‌روزرسانی AJAX با fragments ووکامرس، تغییر تعداد/حذف، کد تخفیف، نوار پیشرفت ارسال رایگان.
- **تسویه‌حساب:** نمایش مرحله‌ای (مشخصات، آدرس، ارسال، پرداخت) روی فرم استاندارد ووکامرس؛ استان‌های ایران به فارسی؛ اعتبارسنجی موبایل `09xxxxxxxxx` و کد پستی ۱۰ رقمی (اعداد فارسی هم پذیرفته و تبدیل می‌شوند).
- **ارسال:** روش‌هایی که در عنوانشان «تهران» آمده (مثل «پیک تهران») فقط برای استان تهران نمایش داده می‌شوند؛ وقتی ارسال رایگان فعال شود، پست پولی پنهان می‌شود (فیلترهای `saayeh_is_tehran_only_rate` و `saayeh_hide_paid_when_free`).
- **علاقه‌مندی‌ها بدون افزونه:** کاربران واردشده در user meta، مهمان‌ها در کوکی؛ ادغام خودکار پس از ورود؛ برگه و تب «علاقه‌مندی‌ها» در حساب کاربری.
- **فرم تماس** با nonce و honeypot (کدکوتاه `[saayeh_contact]`).
- **دسترس‌پذیری:** اهداف لمسی ۴۴ پیکسل، حالت فوکوس، پیوند پرش به محتوا، تله‌ی فوکوس در کشوی سبد، پشتیبانی از `prefers-reduced-motion`.
- **بدون وابستگی به jQuery** در اسکریپت پوسته (فقط برای گوش دادن به رویدادهای خود ووکامرس، اگر بارگذاری شده باشد).

## محدودیت‌های شناخته‌شده

- تاریخ‌ها میلادی‌اند؛ برای تاریخ شمسی از افزونه‌هایی مثل «پارسی دیت» یا «WP Parsidate» استفاده کنید.
- تسویه‌حساب/سبد خرید بلوکی ووکامرس استایل کامل این پوسته را ندارد و درگاه زرین‌پال در آن ثبت نمی‌شود؛ از کدکوتاه‌های کلاسیک استفاده کنید.
- فرم تماس از `wp_mail` استفاده می‌کند؛ برای ارسال مطمئن ایمیل یک افزونه‌ی SMTP نصب کنید.

## مشارکت (Contributing)

از مشارکت شما استقبال می‌کنیم.

1. مخزن را fork کنید و برای هر تغییر یک شاخه‌ی جدا بسازید.
2. کد PHP را مطابق [استاندارد کدنویسی وردپرس](https://developer.wordpress.org/coding-standards/wordpress-coding-standards/) بنویسید؛ همه‌ی خروجی‌ها escape شوند و ورودی‌ها sanitize و با nonce بررسی شوند.
3. همه‌ی متن‌های رابط کاربری با توابع ترجمه و دامنه‌ی `saayeh` نوشته شوند. پس از تغییر متن‌ها فایل `languages/saayeh.pot` را با `wp i18n make-pot . languages/saayeh.pot --domain=saayeh --exclude=demo` به‌روز کنید.
4. پیش از ارسال: `find . -name '*.php' -exec php -l {} \;` و `jq . demo/demo.json` را اجرا کنید و پوسته را روی یک نصب تازه‌ی وردپرس + ووکامرس امتحان کنید.
5. **هیچ کلید، مرچنت کد، رمز یا اطلاعات شخصی** را در کد یا demo.json قرار ندهید.
6. ساختار `demo/demo.json` باید با قرارداد افزونه‌ی درون‌ریز (نسخه‌ی ۱ طرح‌واره) سازگار بماند.
7. Pull Request را با توضیح تغییر و در صورت امکان تصویر قبل/بعد ارسال کنید. با ارسال مشارکت، می‌پذیرید که تحت مجوز GPL-2.0-or-later منتشر شود.
