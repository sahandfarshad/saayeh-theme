A minimal, RTL-first WooCommerce theme for Persian clothing stores.

== Description ==

Saayeh (سایه) is a calm, minimal storefront theme designed right-to-left for
Persian (fa_IR) WooCommerce stores: Vazirmatn typography, a slide-out cart
drawer with free-shipping progress, a plugin-free wishlist, live product
search, size/color/price filters, color swatches, a stepper-styled checkout
with Iranian address fields and validation, and a built-in Zarinpal (API v4)
payment gateway. See README.md (Persian) for full documentation.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → saayeh.zip → Activate.
2. Install and activate WooCommerce.
3. Optional: install the "Saayeh Demo Importer" plugin to import demo/demo.json.
4. Enable Zarinpal in WooCommerce → Settings → Payments and enter your merchant ID.
